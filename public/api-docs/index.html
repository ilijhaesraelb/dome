Use an existing token instead
Signing in fetches a real user access token from Supabase Auth and feeds it into Swagger's Authorize dialog (bearerAuth) automatically, plus attaches it & the publishable key as headers on every "Try it out" call. Endpoints that don't require auth work without signing in. This page never sends your password anywhere except directly to your own Supabase project's auth endpoint.
